# Commercial Loan Portfolio & Credit Risk Analytics

## Project Overview

This project demonstrates the development of an interactive Commercial Loan Portfolio and Credit Risk Analytics solution using a fictional lending dataset.

The dashboard was designed to provide management-level visibility into portfolio performance, credit risk, concentration risk, maturity exposure and business performance.

The project combines financial analysis, credit-risk knowledge and business intelligence techniques to transform raw lending data into actionable portfolio insights.
